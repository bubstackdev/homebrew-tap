# Bubstackdev Tap

## How do I install these formulae?

`brew install bubstackdev/tap/<formula>`

Or `brew tap bubstackdev/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "bubstackdev/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
